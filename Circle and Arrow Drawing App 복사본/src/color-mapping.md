# 색상 매핑

기존 색상 → 새 색상:
- `#F5E6D3` (크림) → `#FFFFFF` (흰색)
- `rgba(245, 230, 211, X)` → `rgba(255, 255, 255, X)`
- `#3D2F2A` (다크 브라운) → `#2A2A2A` (다크 그레이)
- `#2C231F` (더 어두운 브라운) → `#4A4A4A` (미디엄 그레이)

Detail 패널:
- 배경: #4A4A4A
- Label: rgba(255, 255, 255, 0.6)
- 텍스트: #FFFFFF
- 입력 필드 배경: #2A2A2A
- 입력 필드 텍스트: #FFFFFF
- 입력 필드 placeholder: rgba(255, 255, 255, 0.3)
- 보더: rgba(255, 255, 255, 0.3)
